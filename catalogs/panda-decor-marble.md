## Изделие

- Панель **2800 × 1200 мм, толщина 3 мм**, вес 19 кг; состав: каменная крошка + декоративное покрытие; влагостойкий материал.
- В программе соответствует пресету `marble` (2800×1200).
- **Блеск: матовый** (подтверждено пользователем). **Текстура очень похожа на камень, даже наощупь** — в промпте описывать как
  матовый природный камень с рельефной каменной фактурой, без глянца и зеркальных отражений. Интерьерные рендеры каталога
  выглядят глянцевее реальности — не ориентироваться на них.
- **Рисунок продолжается, не повторяется, тянется как бы через всю стену** (подтверждено пользователем): соседние панели
  образуют единую поверхность с непрерывным рисунком; стыки не должны разрывать/дублировать прожилки.
  Для промпта: рисунок камня непрерывный по всей облицовке, швы — только лёгкая линия, рисунок через шов продолжается.
- **Панель можно класть горизонтально** (подтверждено). У разных расцветок рисунок направленный (419-20 — вертикальная
  слоистость, 044 — диагональные золотые прожилки), поэтому при повороте панели рисунок поворачивается вместе с ней;
  в промпте указывать направление рисунка относительно реальной укладки.

## Решения для будущей реализации

- Профиль — отдельная сущность: линейка (для 3 мм / для бамбука) × тип × цвет × покрытие (матовое/глянцевое/без).
  Список цветов зависит от типа панели; «обычный алюминий» всегда доступен.
- Для мрамора промпт: матовый камень, непрерывный рисунок через всю облицовку, швы незаметные, направление рисунка с учётом
  поворота панели; не использовать слова «глянец», «отражение».
- Образец — вся панель «в лоб» (рисунок целиком) + круг для цвета/фактуры; интерьерные рендеры не использовать.
- Для непрерывного рисунка через панели в схеме/промпте нужен признак «рисунок сквозной» (для мрамора всегда включён);
  при необходимости — единая «большая картинка» на всю облицовку, а не по панелям (решить при реализации).
