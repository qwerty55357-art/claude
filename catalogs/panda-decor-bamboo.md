## Как устроен PDF

- Сделан в WPS Presentation, **текстового слоя нет**: каждая страница — одно JPEG ~1536×1024 (артикулы прочитаны глазами, список подтверждён пользователем).
- Страница расцветки: слева интерьерный рендер (**не использовать** — идеализирован, нейросетевой), справа артикул, описание
  (блеск/покрытие), **круглая вырезка-приближение** и **высокая плоская полоса образца «в лоб»** (~355×825 px, ≈3 мм/px).
- Для программы нужны именно полоса и круг; цвет берётся по центру образца.
- Страницы расцветок: 5–20 (первые 16), затем 23–32, 34–36, 38–40. Остальные — титул, разделители коллекций, профили (42–48).

## Все панели одинаковые

2900 × 1150 мм, толщина 5 мм, вес 11 кг, основа — прессованное бамбуковое волокно.
В программе это пресет `bamboo29` (2900×1150). Уникален только артикул расцветки.

## Профили (стр. 42–48) — артикулов нет, только тип + цвет

Типы: торцевой, угловой внешний, угловой внутренний, соединительный (две формы), универсальный угол 15/30/50 мм,
молдинг 15/30/50 мм. Цвета: **золото, чёрный, розовое золото, шампань** (молдинг — ещё серебро, уточнить).
Сейчас промпт описывает профиль как «светло-серый матовый алюминий» — для золотых/чёрных профилей это ошибка.

## Решения, принятые в обсуждении (реализация — только после go-ahead)

- Модель материала: двухуровневая — тип (бамбук 2900×1150 и т.д.) → расцветка, **название расцветки = реальный артикул**,
  уникален. Старые id пресетов остаются «расцветкой по умолчанию» для старых проектов.
- Параметр «Цвет профиля» (золото / чёрный / розовое золото / шампань [+серебро для молдинга]) → в схему и в JSON-промпт.
- Образцы: уменьшенные (base64) встраивать в HTML; в папки архива класть файлы образцов только для использованных расцветок;
  базовый цвет — среднее по центру образца; блеск/покрытие — из описания (matt / satin / gloss / mirror / metal).
- Особые случаи: зеркальная «Водная гладь», металл, блестящие («под краску»), серии P/V с узором.
- Другие пресеты программы (гибкий мрамор, рейки, обе «скалы») этим каталогом **не закрыты** — ждём остальные каталоги.
- Запрос поставщику «Панда Декор»: файлы декоров в высоком разрешении (источник полос); фото живых образцов — выборочно,
  только если цвет/фактура в каталоге не совпали.

## План разбора, когда будет go-ahead

1. Достать полосу и круг каждой расцветки из страниц (PyMuPDF/Pillow), вырезать, нормализовать.
2. Контактный лист «артикул → образец» на сверку с пользователем.
3. Только после подтверждения — встроить в программу, обновить промпт (`materials[]`), тесты (`tests/prompt_rules.js`),
   не ломая открытие старых проектов.
