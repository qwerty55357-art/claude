# Индекс материалов «Панда Декор» для программы

Статус: **сводка данных, в программу (`raskroy.html`) ничего не внесено.** Дата: 2026-10-05.
Источники: четыре PDF-каталога (`panda-decor-bamboo.md`, `panda-decor-slat.md`, `panda-decor-marble.md`,
`panda-decor-polyurethane.md`) и архив фотографий образцов `f12b7d50-1.zip` (в репозиторий не кладётся).

## Правила, принятые пользователем

1. **Имя файла = артикул.** Новинки, которых ещё нет в каталогах, получают артикул по имени файла (запоминается как есть).
2. **Если имя файла и написание в каталоге расходятся — правильно написание из каталога** (см. «Расхождения»).
3. **Архив = позиции из наличия**, поэтому он неполный. **В программе пока нужны только варианты из архива.**
   Позиции каталога без файла (J0078 панелью, 8039, рейки 5001 и 5003) — пока не нужны.
4. **В артикулах только латиница.**
5. Фото сделаны **на расстоянии 30 см** от материала; размер образца оценивать, сравнивая с интерьерными фото каталогов.
6. Разные тона на фото одного артикула (например 8190 панель/рейка) — следствие разной съёмки и баланса белого.
7. **Скалы, полиуретан:** цвет — белый гипсовый; покраска и швы — решение заказчика (в программе не моделируются).
8. **Типы материалов** (программа): бамбуковая панель 2900×1150 (`bamboo29`), реечная 2900×150 (`slat`), гибкий мрамор
   2800×1200 (`marble`), скалы `rockL` 2900×1200 и `rockS` 2900×600 (полиуретан). Остальные пресеты не затрагиваются.
9. Пять других моделей полиуретана (L3-11, H3-21-1, H3-1-1, K3-2, H3-14) в программу не добавляются.

## Как называть файлы

- Образец панели «в лоб»: `<артикул>.jpg` (тип определяется по артикулу, префикса нет).
- Рейка: `Рейка <артикул>.jpg`; для парных расцветок — `Рейка P3 и V3.jpg` (одна расцветка на пару, одно фото).
- Артикулы только латиницей, регистр и дефисы — как в каталоге (`J035`, `YK-105`, `741-A295`, `80205-4`).
- Скалы и зеркало без артикула: `Большая скала`, `Маленькая скала`, `Водная гладь`.

## Масштаб фото

Съёмка с расстояния ~30 см. Кадр ~1280×1280 px, оценка охвата **≈ 25–35 см по стороне, ≈ 0,2–0,3 мм на пиксель**.
Проверка по рейкам: в кадре ~9 рёбер по ~30 мм ≈ 27 см. Это приблизительно (±15 %); точный масштаб при необходимости
уточнить на одном-двух образцах с известным размером.

## Профили (артикулов нет)

- **Бамбуковая линейка:** торцевой, угловой внешний/внутренний, соединительный (две формы), универсальный угол
  15/30/50 мм, молдинг 15/30/50 мм; цвета золото, чёрный, розовое золото, шампань.
- **Линейка для панелей 3 мм (мрамор):** торцевой, H-образный, угловой внешний, соединительный (ребристый) — белый, золото,
  чёрный, серебро; универсальный угол — белый, золото, чёрный матовый, серебро, розовое золото, чёрный глянцевый;
  молдинг — матовые: серебро, золото, чёрный; глянцевые: серебро, золото, чёрный; **+ обычный алюминий**.
- **Молдинг не зависит от линейки товара:** любой цвет молдинга (в т.ч. серебро матовое/глянцевое, золото, чёрный) можно
  использовать с любой панелью — бамбук, рейка, мрамор; набор цветов молдинга общий.
- В программе: профиль = линейка × тип × цвет × покрытие (см. `panda-decor-marble.md`); для молдинга линейка не выбирается.

## Реализация в программе (сделано, 2026-10-05)

- **Каталог встроен в `raskroy.html`** (блок между `<!--[КАТАЛОГ:НАЧАЛО]-->` и `<!--[КАТАЛОГ:КОНЕЦ]-->`): 39 бамбуковых, 21 реечная
  (P/V — парами), 8 мраморных расцветок + рельефные образцы двух скал; миниатюры 512 px. Блок генерирует
  `tools/build_catalog.py` — руками не править.
- **Модель материала:** тип (`bamboo29`, `slat`, `marble`, `rockL`, `rockS`, `custom`) + расцветка `<тип>:<слаг артикула>`
  (например `bamboo29:8190`, `slat:p3_v3`, `slat:8070_wave`). Название расцветки = артикул. Старые проекты (только типы)
  открываются без изменений: раскрой, схема, смета и замечания совпадают с версией без каталога (тест `tests/catalog_compat.js`),
  ядро расчёта не менялось. Расцветка, которой нет в каталоге, при открытии проекта заменяется типом с предупреждением.
- **Выбор:** в разделе «Панель» — тип + «Расцветка (артикул)» (сетка миниатюр с поиском); тот же пикер — для заполнения проёма,
  деталей стены и откосов.
- **Цвета:** на схеме и раскрое — **условные** цвета (у каждой расцветки свой; если в проекте два материала получили один цвет,
  один из них меняется). **Реальный цвет** (по образцу), описание и фото образца идут **только в промпт и архив**.
- **Промпт:** `materials[]` у расцветок — `schema_fill` (цвет-маркер заливки), `real_color_hex`, `texture_hint`, `sample_file`;
  правила по типам (мрамор — матовый, рисунок сквозной; скала — белый гипс, рельеф до 35/80 мм; рейка; бамбук — по образцу).
  Блеск указывается только там, где он известен.
- **Архив для нейросети:** в папке каждого фото — `материалы.jpg` (доска образцов: рамка образца = цвет заливки на схеме,
  подпись = артикул) и `образцы/<артикул>.jpg` только для использованных материалов.
- **Цвет профилей** — один на проект (обычный алюминий / белый / золото / серебро / чёрный матовый / чёрный глянцевый /
  розовое золото / шампань); по умолчанию — обычный алюминий (описание как раньше); задаётся в промпте (глоссарий заглушки,
  жёсткое требование, поле `profiles`), на схеме линии остаются маркерами.

### Как добавить новинки

1. Положить фото в папку/zip: имя файла = артикул (рейка — `Рейка <артикул>.jpg`), латиница в артикуле.
2. Добавить строку с описанием в таблицу `META` в `tools/build_catalog.py` (иначе попадёт «без описания (новинка)»).
3. `python3 tools/build_catalog.py <папка-или-zip> raskroy.html` и прогнать `tests/` (см. ниже).

Тесты: `tests/catalog_compat.js` (старые проекты + модель), `tests/catalog_ui.js` (пикер), `tests/catalog_prompt.js` (промпт, архив, цвет
профилей), `tests/prompt_rules.js`, `tests/viz_smoke.js`.

## Открытые вопросы (не блокируют дальнейшую работу)

- Блеск (матовый/сатин/глянец) для бамбуковых расцветок, кроме перечисленных выше: **оставлен как есть (не задаётся)**,
  решение пользователя; в промпт не выдумывать, брать только известное.
- У 9 новинок размер считаем 2900×1150×5 (бамбук); описаний от поставщика нет.

Закрыто пользователем: артикул пишется `P74-2` (без пробела); **молдинги бывают серебряными в любой линейке** — молдинг
не зависит от линейки товара (см. «Профили»).
